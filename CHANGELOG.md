# Changelog

## 1.0.0

First public release.

- **Spotify tab:**
  - personal mixes (Daily Mix, Discover Weekly, Release Radar…);
  - new releases from followed, top and most-liked artists;
  - Top 50 Global and USA charts;
  - an in-tab page for every playlist and release.
- **Liked Songs tab:**
  - search, sorting, playback and a context menu;
  - removing likes with undo;
  - an optional copy in Nuclear's playlists.
- **Nuclear Dashboard:** mixes, charts and releases are provided to Nuclear's built-in Dashboard page.
- **Login:** OAuth PKCE with your own Spotify app; the redirect address is picked up from the clipboard.
- **Languages:** English and Russian, following Nuclear's language setting.
